- **factory 0.4.0, review round 4 fixes (f040-fix5)** (`factory/template/`; not yet versioned or synced). The
  critic's round 2 on the merged branch, code side (A1, A2, A4-A9):
  - A1 (blocker): for a read-only agent `cp` takes only `-R -r -p` and `mkdir` only `-p` (getopt clusters,
    `--` ends the options, no long option), and a target that is, or lies below, an existing symlink is refused
    (macOS `cp -s`/`-l` made a link under the scratch and a plain `cp` then wrote through it to a file outside).
    `ro_agent_scratch` and the new `ro_nolink` live in `factory/template/.claude/hooks/_bash_guard_agents_lib.sh`.
  - A5: the commands a read-only agent may run are their own list `RO_AGENT_CMDS` in that library, pinned by
    `factory/template/scripts/test/test_hooks_agents.jl`; `RO_CMDS` (`_read_only_roots.sh`) is the reference
    roots' only, so a tool added for the roots is no longer granted to an agent.
  - A2: every agent's `_report.md` had asked for a `Verdict:` line, so an implementer's own report passed
    `scripts/lane audit --report` as a review. Now `factory/template/.agents/bodies/_report.md` keeps the common
    rules and a write agent's line 1 `Status: DONE | PARTIAL | BLOCKED`; the new fragment `_verdict.md`
    (`Verdict:` line 1, `Head:` line 2) is rendered by `factory/template/scripts/gen.jl` into `default_mode =
    "read_only"` agents only. `scripts/lane audit --report` (`factory/template/scripts/lane.jl`,
    `report_dispatch` in `factory/template/scripts/_lane_stats.jl`) now requires `Head:` on line 2 exactly, a clean lane
    worktree (`lane worktree is dirty; commit or drop before the audit`) and a ledger `dispatch` whose name is the
    report's base name (before `-<round>.md`) with subagent_type reviewer, critic or verifier (`report <name> is
    not from a read-only reviewer dispatch`); `ledger_rows` carries `subagent_type`. `teammate_idle.sh` accepts
    either final line 1 (`Verdict: …` for a reviewer/critic/verifier, `Status: DONE | BLOCKED` otherwise) and
    its demand names both.
  - A6: while writing, line 1 is `Verdict: PENDING` or `Status: PARTIAL` and is replaced last; `teammate_idle.sh`
    treats both as not reported.
  - A7: a session rooted in a lane worktree: `teammate_idle.sh` also reads the main checkout's `.lanes/reports/`
    (MAIN from `_lib.sh`, as write_guard's `in_main` resolves it).
  - A8: `FACTORY_LEDGER_LINES` (default 2000) is the ledger line budget `precompact.sh` compacts past and
    `dispatch_limit.sh`'s denial names (`run scripts/lane compact; if the ledger stays above N lines it holds
    that many live chains, raise FACTORY_LEDGER_LINES`).
  - A4, A9 (comments and `factory/template/.agents/checks.toml`): the watchdog covers the lock wait (it starts
    before it); `precompact.sh` states `lane compact`'s real retention rule;
    `factory/template/.claude/commands/lane-review.md` step 3 runs `runtests.jl gen hooks --hooks-dir <copy>` live and step 7 names the new audit rules; the
    symlink blind spot says what the guard now does; a watchdog firing after the dispatch append counts the
    lane and denies it (tiny window). `lane-lifecycle/SKILL.md` and the registry comment follow.
  - Review round 1 of this lane (B1, M1, m1, m2): a cp/mkdir target takes no `.`/`..` component on the RAW path
    (abspath folds `..` lexically while the OS follows a symlink before it) and no `$` or backtick in any argument;
    a `cp -R`/`-r` whose source tree holds a symlink (`find -maxdepth 8 -type l`) is refused, since the link would be
    copied under the scratch and written through; `lane audit --report` takes the read-only set from the repo's
    `limits.env` `READ_ONLY_AGENTS` (`reporters` in `factory/template/scripts/_lane_stats.jl`; the template's three
    when absent); an unnamed reviewer dispatch (name `-`) or a Codex run never passes the audit, stated in
    `checks.toml` (lane_tool).
  - Review round 2 of this lane (N1, N2): a glob (`*`, `?`, `[`, `{`, a leading `~`) in any cp/mkdir operand is
    refused next to `$` and the backtick (the shell would expand `dws/*` to a link the scan never saw, and `d/*` was
    a literal to the symlink check); the `cp -R` symlink scan has no depth bound, and a source tree deeper than 8
    levels is refused first (`find -mindepth 9 -print -quit`) so the hook's cost stays bounded; the remaining width
    window is in `checks.toml`.
  - Review round 3 of this lane (P1): cp/mkdir operands are handled as typed inside the argument loop, never stored
    space-joined and re-split (`cp -R "sp ace"` had been scanned as `sp` and `ace`, planting the link); and
    `write_guard.sh` (now sourcing `_bash_guard_agents_lib.sh`, a missing one blocks) refuses a read-only agent's
    Write whose raw path has a `.`/`..` component or an expansion, or whose scratch/report path sits at or below an
    existing symlink below the root (`ro_nolink`): the prefix match alone was lexical.
